# SeeYa

Détecteur de présence mmWave et contrôleur d'éclairage sur ESP32-C3.

- Radars : HLK-LD2410C / HLK-LD2450 (firmware commun)
- Relais, temporisation, Wi-Fi, serveur Web, API HTTP, NTP et horaires hebdomadaires

Statut : **conception initiale**, firmware non encore implémenté.

Voir [l'architecture et la spécification](docs/architecture.md).
