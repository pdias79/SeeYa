# LD2450 : positions et filtrage spatial (première version)

Le firmware SeeYa peut sélectionner LD2410C, LD2450 ou Désactivé dans l'interface Web. Les deux radars utilisent UART1, RX ESP32 GPIO4 (TX radar) / TX ESP32 GPIO5 (RX radar), 256000 bauds, 8N1. Un seul capteur est actif à la fois.

## Trames LD2450
Trame périodique de 30 octets : `AA FF 03 00`, trois groupes de 8 octets (X, Y, vitesse et résolution), terminaison `55 CC`.
- Coordonnées en millimètres, vitesse en cm/s.
- Les valeurs codées utilisent le bit 15 comme indicateur **positif** lorsqu'il est à 1, et **négatif** lorsqu'il est à 0 ; les 15 bits restants donnent la magnitude.
- Groupe de 8 octets entièrement nul : pas de cible.
- Une trame valide actualise l'état et le compteur. Sans trame valide depuis 2,5 s, radar hors ligne et présence false.
- Seules les trames périodiques de détection sont traitées ; commandes de configuration natives et modes spéciaux non implémentés.

Source technique : [Hi-Link LD2450 Serial Communication Protocol v1.02](https://assets.super.so/79c0d2a8-d37a-438f-8fbe-c44778f3b0dd/files/ee2aafb0-f93e-47cd-b722-ad0f9e76b6f7/LD2450_Serial_Communication_Protocol_V1.02_EN.pdf).

## Zone rectangulaire
- Zone facultative, stockée dans la NVS de SeeYa (pas écrite dans la mémoire du module radar).
- Origine au module ; X de -6000 à 6000 mm, Y de 0 à 6000 mm.
- Une cible présente dans la zone suffit à déclarer présence. Si la zone est désactivée, toute cible valide est retenue.
- La présence radar garde l'éclairage allumé puis le délai de maintien prend le relais à sa disparition, comme pour le LD2410C.
- La plage est un filtre logiciel. Elle ne garantit ni la portée physique du radar, ni une précision au millimètre.
- Pas encore de dessin interactif, de polygones, de zones multiples ou de zones d'exclusion.

## API
`GET /api/status` : `sensorType`, `targetCount`, `targets` (valid, xMm, yMm, speedCmS, insideZone), zoneMinX/MaxX/MinY/MaxY, zoneEnabled, presence/health.

`POST /api/radar` : données x-www-form-urlencoded : `type=disabled|ld2410c|ld2450&offDelay=90`.

`POST /api/radar/zone` : `enabled=true|false&zoneMinX=-1500&zoneMaxX=1500&zoneMinY=0&zoneMaxY=4000`.

Les anciennes préférences `radarOn=true` sont migrées implicitement vers LD2410C si le nouveau champ sensorType est absent.

## Tests demandés sur matériel
- Valider trames avec 0, 1, 2 et 3 cibles, signe X/Y, passage hors zone et retour, déconnexion UART.
- Observer les pertes de suivi en position immobile. Le LD2450 n'est pas équivalent au LD2410C pour la présence statique.
- Vérifier la configuration native éventuelle des zones LD2450 depuis un outil externe : SeeYa n'efface pas les filtres natifs.
- Aucune charge secteur durant les essais initiaux ; valider le fonctionnement du relais indépendamment.
